# ThoughtLeap Studios brand guide

ThoughtLeap Studios brings strategy, words and design together so the right people understand a business's value. It delivers the work: brands, websites, pitch decks, apps and events. Events are one service, not the organizing theme of the identity. The live site is https://thoughtleapstudios.com/.

## Lettering

`source/brand-assets/originals/TL_horizontalmark_white.svg` is the original parent artwork by Kayla Griffin. `source/brand-assets/thoughtleap-wordmark.svg` retains the original ThoughtLeap paths and omits the separate `.ai` suffix. STUDIOS is typeset separately in the website lockup. The path changes and source hash are recorded in `source/brand-assets/PROVENANCE.json`.

Preserve these paths and uniform proportions. Never approximate the lettering with a font, retrace it, or generate a replacement. Use the derivative and its embedded JavaScript string for the reflected identity. The larger reflection is part of the live object treatment.

## Object identity

The Studios object is the precision arrow with one bevel per side and a perfectly rigid orange sphere. The broad arrow face remains smooth. The selected metal uses a slightly darker platinum base color, sharp reflections and polished facets; the rendering is light-dependent, so a flat swatch alone is not a material specification.

The live wrapper uses faceColor #A7AFB7, faceRoughness 0.018, bevelRoughness 0.012, sideRoughness 0.018, sideAnisotropy 0, doubleBevel false, reflectionScale 3.2 and sideEngraving true. The side engraving reads BRAND · DESIGN · WEB. Use the full resolved preset, not just these selected values.

The stage is near-black with the existing grounded shadow treatment. Preserve the geometry, light, camera and materials together when matching the deployed object. The source includes dark-mirror, extra-bevel and other experiments; none is selected merely because it exists in code.

## Voice and use

Current lines include “Make the leap.” and “Let your brand show what makes your business special.” Explain deliverables in words a nontechnical business owner recognizes. The polished object demonstrates attention to detail; it does not replace a clear description of the service.

Read OBJECTS.md for Three.js and Remotion setup. The supplied making films are the current web encodes, while the Remotion object-study composition is a separate reusable source tool. Do not describe it as the source of that pre-existing making film.
