# ThoughtLeap brand kits

Start here when creating authorized work for **ThoughtLeap.ai** or **ThoughtLeap Studios**.
This package preserves the identity assets and object source used by the live brands, checked on November 18, 2026. It does not redesign either brand.

| Brand | Start here | Primary use |
| --- | --- | --- |
| ThoughtLeap.ai | [Brand guide](thoughtleap-ai/BRAND-GUIDE.md) | Help people get useful work done with AI and learn to work with it. |
| ThoughtLeap Studios | [Brand guide](thoughtleap-studios/BRAND-GUIDE.md) | Strategy, words and design delivered for the client. |

Read [AGENTS.md](AGENTS.md) before changing an asset. The custom ThoughtLeap lettering is original artwork by **Kayla Griffin**. Use the supplied paths; never replace it with a font.

## What is authoritative

1. Brandon's current instruction and supplied original artwork.
2. The deployed source snapshots identified below, for reproducing the websites as they exist today.
3. The scoped guides and extracted tokens in this package.
4. Historical identity tokens, only where a guide expressly identifies their use.

Deployment proves what is live. It is not blanket creative approval of every historical preset or source-file comment. Original source comments and provenance records are preserved unchanged, including older review labels.

## Included

- Parent-brand SVG and PNG logos, original custom white wordmark, and the Studios derivative with exact path provenance.
- Separate current website palettes and typography, plus the parent identity palette retained for existing collateral.
- Studios procedural Three.js geometry, materials, reflections, shadows, interaction and collision code.
- A resolved Studios production preset and the original Remotion composition.
- The two actual web film encodes (640 and 960 pixels wide) and poster, committed as ordinary files. These are web deliveries, not a claim to a new 4K master.
- Fonts with their supplied OFL notices, environment maps, a local object viewer, checksums and a verification script.

## Use the objects

See [Studios object setup](thoughtleap-studios/OBJECTS.md). No GLB or Blender file is asserted as the master: the live Studios object is generated by the included Three.js source and settings. The parent site's earlier object is separately preserved under `thoughtleap-ai/source/site/js/stage.js`.

## Check integrity

Run `python3 scripts/verify.py` from this directory. [manifest.json](manifest.json) records each packaged file, its hash, and the original source for unchanged files. [Production evidence](verification/production.json) records what was compared with the live sites.

## Sharing and rights

This is a brand-only distribution snapshot. It excludes private research, correspondence, client working files, deployment credentials and unrelated project history. Read [RIGHTS.md](RIGHTS.md). Availability of a link does not grant permission to impersonate the brand or reuse its identity for unrelated work.

An agent needs a tool that can fetch a URL or clone/download a repository. A public URL removes the GitHub sign-in requirement; it cannot give an agent browsing capabilities it does not have.
