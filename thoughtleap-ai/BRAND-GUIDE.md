# ThoughtLeap.ai brand guide

ThoughtLeap.ai helps people get useful work done with AI in plain English. **For The Humans.** is the accompanying line. The live site is https://thoughtleap.ai/.

## Identity artwork

Use `logos/svg/` and `logos/png/`. The outlined ThoughtLeap lettering is original artwork by Kayla Griffin, not a typesetting instruction. Keep `.ai` in parent wordmark assets where supplied. Preserve aspect ratio and original colors. Navy marks suit light backgrounds; white marks suit dark backgrounds. Do not borrow the Studios orange for the parent brand.

## Current website

The deployed source is the October 20 ink treatment, preserved at commit `b795dee288ac2ce5ff7e69afaebabd6bbf71b458` in carson-brand. The homepage was compared byte for byte with the local release on November 18, 2026. Use `tokens.web.json` and `source/site/css/site.css` when matching the current website.

## Existing identity and collateral

`tokens.identity-20260610.json` preserves the earlier Canva identity system. Its principal colors include navy #203B6B, vermilion #E8542B and cream #F4F3EE; its text face was Open Sans. That is historical identity context for existing collateral, not the current website specification. No newly approved universal print system is claimed here. Keep an existing deliverable's system consistent rather than mixing palettes and fonts.

## Three dimensional mark

`source/site/js/stage.js` is the actual parent site's earlier Three.js stage. It includes its own surface treatment and enamel dot. It is distinct from Studios' later smooth-face and spherical object. Preserve this distinction when reproducing production. Its environment is `source/site/assets/studio.hdr`; the dependency is Three.js 0.160.0 as declared by the live site's import map.

Use original robot photographs only if a separate brief calls for them and supplies the asset and usage terms. They are not included in this compact identity kit.
